真题卡片 (Quiz Card) 内部结构设计

我们采用了“单页沉浸流” (A)，每道题是一张卡片，默认隐藏答案。下面请确认卡片内部的排版和答案展开交互方式。

1

内联手风琴 (Inline Accordion)

点击“查看答案”后，答案内容直接在题目下方平滑展开。符合最常见的阅读习惯。

Q1: CSS 权重问题 (8 marks) CSS

What colour is the button text, and how does the browser choose between the four rules?

查看答案与解析 ▼
Model answer:
The button text is GREEN.
ID always takes precedent over classes and type selectors.
2

翻转卡片 (Flip Card / Flashcard)

点击卡片任意位置或翻转按钮，整个卡片翻转显示背面的答案。适合强记忆型的刷题体验，但对长答案支持不够友好。

↻ 翻转
Model answer:
The button text is GREEN.
ID always takes precedent over classes and type selectors.
3

卡片内分栏 (Card Split View)

在较宽屏幕上，卡片左侧是题目，右侧是答案区域（默认覆盖毛玻璃遮罩，点击解锁）。在移动端退化为上下布局。
