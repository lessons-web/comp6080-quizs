# COMP6080 前四周课程知识点按周详细版

## Week 1

### 主题

前端课程导入，建立 `HTML + CSS` 基础认知，先把页面结构、样式规则和布局方式打牢。

### 知识点

- 课程导论与整体学习路径：介绍这门课为什么重要、前端在行业里的位置，以及课程后续会怎样从基础逐步走向现代前端开发。
- HTML Fundamentals：学习 HTML 文档结构、常见标签、页面基础骨架，以及如何用语义化标签组织内容。
- HTML 中的图片处理：理解网页中插入图片的基本方式，包括尺寸、替代文本和基础展示规则。
- SVG 图片基础：认识 SVG 作为矢量图格式的特点，理解它和普通位图在网页中的不同使用场景。
- 更多 HTML 标签与页面结构：补充常见结构类与内容类标签，帮助学生更完整地搭建页面语义结构。
- CSS Rules：掌握 CSS 选择器、声明、层叠、优先级等核心规则，建立“样式为什么会生效”的基础理解。
- CSS Formatting：学习文本、边距、内边距、边框、显示方式等基础格式化能力。
- CSS Layouts：理解网页常见布局思想，知道如何把多个元素组织成稳定页面结构。
- CSS Flexbox：学习一维布局工具，掌握主轴、交叉轴、对齐、分布等常见用法。
- CSS Z-index：理解元素层叠顺序、定位上下文，以及为什么有些元素“盖不上去”。
- CSS Preprocessors：认识 CSS 预处理器的作用，例如变量、嵌套、复用等，理解它们如何帮助样式工程化。

## Week 2

### 主题

从纯 `HTML/CSS` 过渡到更贴近真实开发的前端基础，包括响应式设计、开发工具、JavaScript 语法和 `Node / NPM` 生态。

### 知识点

- Mobile CSS：学习面向移动端的样式设计思路，理解响应式页面和不同设备适配的基本方法。
- 使用 CSS Frameworks：认识常见 CSS 框架的价值，理解什么时候应该自己写样式，什么时候可以借助框架提高效率。
- Dev Tools：掌握浏览器开发者工具的基础使用方法，包括查看元素、调试样式、检查网络和定位前端问题。
- JavaScript 语言特性与基础语法：进入 JavaScript 基础，掌握变量、条件、循环、函数、对象等核心语法。
- JavaScript Ecosystem：理解 JavaScript 不只是浏览器脚本，还包含运行时、工具链、库、框架和包管理等更大的生态。
- Node Package Manager：学习 `npm` 的基本使用，包括安装依赖、管理项目包和理解 `package.json` 的作用。
- JavaScript Advanced Functions：进一步理解函数作为一等公民、回调、高阶函数等更现代的 JavaScript 写法。
- NPM Advanced：补充更进一步的 `npm` 使用方式，例如脚本、版本、依赖管理和更贴近项目开发的实践。
- JavaScript 与 NodeJS Demo：通过示例把 JavaScript 语法、Node 运行环境和 NPM 使用方式串起来，帮助学生把零散知识点落到实际操作里。

## Week 3

### 主题

把 JavaScript 放回浏览器环境里，开始理解浏览器端脚本如何与页面、事件、表单和本地存储发生关系。

### 知识点

- 浏览器端 JavaScript Intro：介绍浏览器中的 JavaScript 是如何被引入和执行的，以及它与 NodeJS 脚本的区别。
- Browser DOM：理解 DOM 是什么，学习如何通过 JavaScript 读取、修改和创建页面元素。
- Browser Events：掌握事件机制，理解点击、输入、提交等交互是如何被前端代码监听和处理的。
- Browser Forms：学习表单在浏览器中的工作方式，理解输入、提交、校验和用户交互流程。
- Browser LocalStorage：认识本地存储的用途，理解前端如何在浏览器里保存简单数据并在页面刷新后继续使用。
- JavaScript Closures：学习闭包概念，理解函数作用域、内部状态保存，以及它在前端代码中的常见价值。
- JavaScript Web Demo：通过浏览器端示例把 DOM、事件、表单和脚本交互整合在一起，帮助学生形成“网页行为是如何被驱动的”整体认识。

## Week 4

### 主题

进入前端异步与网络通信，理解浏览器如何与服务器交换数据，以及 JavaScript 如何处理异步流程。

### 知识点

- Data Interchange：学习前后端数据交换的基本概念，重点理解结构化数据在网络中的组织与传递方式。
- AJAX Intro：建立异步请求的整体认知，理解为什么前端不需要每次都整页刷新也能更新内容。
- AJAX XHR：学习 `XMLHttpRequest` 的基本工作方式，理解早期浏览器异步请求是如何实现的。
- AJAX Fetch：学习 `fetch` API 的基本用法，理解现代前端如何发起网络请求并处理响应。
- JavaScript Async Callbacks：理解回调在异步编程中的作用，以及它为什么容易带来结构复杂和可读性问题。
- JavaScript Async / Await：学习 `async/await` 语法，理解它如何让异步流程写得更接近同步逻辑。
- HTTP Server：建立前端与服务器通信的基本视角，理解请求、响应、接口以及客户端与服务端的交互关系。

## 前四周整体主线

- Week 1：先打 `HTML / CSS` 基础
- Week 2：把页面能力扩展到响应式、调试工具和 JavaScript 生态
- Week 3：把 JavaScript 放到浏览器里，开始真正驱动页面行为
- Week 4：让前端与服务器通信，进入异步和网络阶段
