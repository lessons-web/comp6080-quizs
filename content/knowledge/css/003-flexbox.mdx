Flexbox 是 CSS 布局的一次革命：以前靠 `float`、`inline-block`、`table` 这些"旁门左道"实现的对齐方式，现在一个 `display: flex` 就能解决。核心心智模型就一句话：**Flex 是「父容器管一堆子项」的系统**。搞清楚谁是父、谁是子，再搞清楚主轴/交叉轴，所有布局都能推出来。

## 1. 基本词汇

```html
<ul class="flex-parent">
  <li class="item">1</li>
  <li class="item">2</li>
  <li class="item">3</li>
</ul>
```
```css
.flex-parent { display: flex; }
```

| 角色 | 谁来写属性 | 常用属性 |
|---|---|---|
| 容器（父） `.flex-parent` | 父写 | `flex-direction / justify-content / align-items / flex-wrap / gap` |
| 项目（子） `.item` | 子写 | `flex-grow / flex-shrink / flex-basis / align-self / order` |

> 💡 95% 的布局只需在**父容器**上写 4 个属性就能搞定。

## 2. 两个轴：主轴 vs 交叉轴

Flex 所有对齐属性都跟**轴**绑定。轴由 `flex-direction` 决定：

```
flex-direction: row;            主轴 👉 水平 ，交叉轴 👇 垂直
flex-direction: row-reverse;    主轴 👈 水平
flex-direction: column;         主轴 👇 垂直，交叉轴 👉 水平
flex-direction: column-reverse; 主轴 👆 垂直
```

牢记：
- **主轴**（main axis）：子项排列的方向；子项大小的「长」在这个方向算。
- **交叉轴**（cross axis）：垂直于主轴的那根轴；用来看"一行"内高低不齐的子项怎么对齐。

## 3. 容器属性：四大天王

### ① `justify-content` —— 主轴上怎么"分配多余空间"

可选值：`flex-start / flex-end / center / space-between / space-around / space-evenly`

```
justify-content: center;      ⇒ [  ⬜⬜⬜  ]
justify-content: space-between;⇒ [⬜    ⬜    ⬜]（两端贴边）
justify-content: space-around; ⇒ [  ⬜  ⬜  ⬜  ]（两端半倍空隙）
justify-content: space-evenly; ⇒ [  ⬜   ⬜   ⬜  ]（空隙全相等）
```

### ② `align-items` —— 交叉轴上"每个子项怎么对齐"

可选值：`stretch（默认） / flex-start / center / flex-end / baseline`

```
align-items: stretch; ⇒ 子项高度拉满一行
align-items: center;  ⇒ 一行里所有子项**垂直居中**（最常用）
align-items: flex-start; ⇒ 全部贴顶部
align-items: baseline;  ⇒ 按文字基线对齐（中英文混排很有用）
```

### ③ `gap` —— 子项之间统一的缝（推荐！）

```css
.nav { display: flex; gap: 16px; }
```

比写 `.nav > * + * { margin-left: 16px; }` 简洁，且 Flex 的 `gap` **不会产生 margin 折叠问题**。还能写 `row-gap` / `column-gap` 分开控制横竖。

### ④ `flex-wrap` —— 一行塞不下怎么办

- `nowrap`（默认）：硬塞一行，哪怕子项被挤压变形；
- `wrap`：塞不下就换行（多行，配合 `align-content` 控制多行之间的分配）。

## 4. 项目属性：三个 `flex-*`

`flex` 是一个简写：

```css
flex: 1 1 0%;   /* flex-grow flex-shrink flex-basis */
```

| 属性 | 作用 | 常见值 |
|---|---|---|
| `flex-grow` | 有剩余空间时，"按比例分肉" | 0（不拿，默认）；1（平分） |
| `flex-shrink` | 空间不够时，"按比例缩水" | 1（默认参与缩）；0（坚决不缩） |
| `flex-basis` | 在分配前子项的"基准尺寸" | `0%` / `120px` / `auto`（默认，看 width） |

**最常见的一个组合**：

```css
/* 三块，让中间那块撑满剩余空间，左右各固定 200 */
.layout { display: flex; gap: 12px; }
.layout .aside-left  { flex: 0 0 200px; }   /* 不伸不缩，死 200 */
.layout .main        { flex: 1 1 0%;   }   /* 剩下全吃掉 */
.layout .aside-right { flex: 0 0 240px; }   /* 不伸不缩，死 240 */
```

## 5. 一次性记牢：20 个常见布局

### （1）水平 + 垂直绝对居中（万年需求）
```css
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 400px;
}
```

### （2）左 Logo 中 Nav 右用户（Header 三件套）
```css
.header { display: flex; align-items: center; gap: 16px; }
.header .nav { display: flex; margin: 0 auto; gap: 24px; }
/* 或 header justify-between，nav 自己写 gap 也行 */
```

### （3）两列等高卡片
```css
.cards { display: flex; gap: 16px; align-items: stretch; }
.card  { flex: 1 1 0%; display: flex; flex-direction: column; }
.card .footer { margin-top: auto; }   /* 卡片底部的按钮"自动吸底" */
```

> 👏 `margin-top: auto` 配合 Flex 是"单元素吸到底部/推到最右"的神器，比绝对定位稳定得多。

## 6. 高频错题的坑

1. **`justify-content` 不生效**：90% 情况是主轴方向根本没有剩余空间 —— 父容器宽度就等于所有子项宽度之和。要么让父更宽，要么某一项写 `flex:1` 撑开。
2. **`align-self` 不生效**：它管的是交叉轴；主轴上的单个子项对齐要用 `margin-left:auto` 这种。
3. **长文字把 Flex 撑破**：子项默认 `min-width: auto`，文字不折行会撑开。修复：`min-width: 0` + `overflow:hidden` + `text-overflow: ellipsis`。
4. **`flex-wrap` 下内容不齐**：多行时要用到 `align-content`，默认 `stretch`；想行之间贴顶部就要写 `align-content: flex-start`。

## 7. 自我核对清单

- ✅ 在父容器上写的属性：`display:flex`、主方向、主轴对齐、交叉轴对齐、gap；对吗？
- ✅ 有没有把 `justify-content: center` 写到了垂直方向的布局上（应该是 `align-items`）？
- ✅ 撑满剩余空间用 `flex: 1 1 0%`，而不是 `width: 100%`？
- ✅ 长文本子项是否加了 `min-width: 0` 避免撑破？
- ✅ 按钮吸底、吸边都用了 `margin-xxx: auto` 吗？
