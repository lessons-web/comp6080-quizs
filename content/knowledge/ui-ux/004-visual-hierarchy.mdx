视觉层级（visual hierarchy）要解决的问题是：**在一个界面里，让最重要的东西最突出，让次要的东西安静下来**。用户的注意力是稀缺资源，层级就是替用户「排好优先级」。它有六个常用手段，考试常考「给一个界面，问哪个元素被强调、用了哪几个手段」。

## 1. 六个手段逐一拆解

### 1.1 Size（尺寸）

- 越大 = 越重要。标题比正文大，主按钮比次要按钮大。
- 尺寸差要**足够明显**才有效。48px 和 46px 之间看不出来；48px 和 16px 差别才够。

### 1.2 Color（颜色）

- 越**亮/越饱和** = 越重要。品牌主色、亮色通常给到关键按钮或强调文字。
- 大量灰阶做背景和辅助文字，把颜色留给真正重要的那一个点。

### 1.3 Contrast（对比）

- 对比越强越吸睛。白底黑字、亮色块上的深色文字都属于强对比。
- 想让人注意到某个元素，就让它**与周围不一样**（亮暗、大小、疏密都可制造对比）。

### 1.4 Spacing（留白）

- 元素周围**大 margin / 大留白**会制造「重要感」。留白越多，这块内容越像被「请上台」。
- 反过来，元素挤在一起就显得次要、像附属信息。

### 1.5 Alignment（对齐）

- 直觉会说「对齐 = 整齐」，但视觉层级里要记住一个反直觉点：**适当的「不对齐」反而吸睛**。
- 当所有元素都沿网格对齐，唯独一个元素**破格错位**，它立刻成为视觉焦点。

### 1.6 Repetition（重复）

- 重复的元素会被大脑**归入同一层级**，一起被接收。
- 关键点：重复不仅能「提升」一组元素的一致性，也能**「降级」次要信息**——把它做成大量重复、格式统一的小字，让它**容易被忽略**。

> ⚠️ 常见误区：**忽略 Repetition 也可以用于「降级」**。很多人只把重复当「统一」用，忘了它同样能把次要信息压到背景层，让用户自然跳过。

## 2. 六手段速查表

| 手段 | 如何表达「更重要」 | 反向用法（次要/忽略） |
|---|---|---|
| Size | 更大 | 更小 |
| Color | 更亮/更饱和 | 灰阶、低饱和 |
| Contrast | 与周围差异更大 | 融入背景 |
| Spacing | 留白更多 | 挤在一起 |
| Alignment | —— | 都对时，唯一**不对齐**的更吸睛 |
| Repetition | —— | 大量重复 → 归为次要、易忽略 |

## 3. 界面分析示例（常考题型）

假设一个电商详情页：

```text
┌──────────────────────────────┐
│  [ 商品大图 ]                 │
│                              │
│  ¥ 199            ← 价格     │
│  超舒服的纯棉 T 恤  ← 标题   │
│  已售 1.2 万 · 好评 98%  ← 小字 │
│                              │
│  [    立即购买    ] ← 主按钮  │
│   加入购物车         ← 次按钮 │
└──────────────────────────────┘
```

**分析：哪个元素被强调？用了哪几个手段？**

| 元素 | 是否被强调 | 用了哪些手段 |
|---|---|---|
| 价格 ¥199 | ✅ 强调 | **Size**（大字）+ **Color**（品牌红/亮色）+ **Contrast**（深色字压白底） |
| 主按钮「立即购买」 | ✅ 强调 | **Size**（最大按钮）+ **Color**（实心主色）+ **Spacing**（四周留白多）+ **Contrast** |
| 次按钮「加入购物车」 | ⚪ 次要 | 与主按钮对比 → 描边/浅色、更小（**Contrast** 弱 + **Size** 小） |
| 销量/好评小字 | ⚪ 忽略 | **Repetition**（同格式重复）+ 小字灰字（**Size**/**Color** 弱） |

答题套路：**先指出被强调的元素，再逐条点名用了哪几个手段**（如「价格用了 Size + Color + Contrast」）。

## 4. 反模式（❌ 别这么写）

```text
❌ 所有字一样大、一样黑 → 没有层级，用户不知道先看哪
❌ 到处都是亮色/主色 → 全强调 = 无强调
❌ 认真对齐时把你唯一想突出的东西也对齐进去 → 焦点被淹没
❌ 把次要信息做成大字号高对比 → 抢了主信息的注意力
```

## 5. 小练习

- 想让一段说明文字「看起来不重要」→ 用**小字号 + 灰阶 + 与周围重复的格式**。
- 想突出一个「新」标签 → 用**亮色 + 与周围不同的形状/位置（不对齐）**。
- 想让一个区块「像主角」→ 给它**大大的四周留白（Spacing）**。

## ✅ 自查清单

- ✅ 能默写六要素：**Size / Color / Contrast / Spacing / Alignment / Repetition**？
- ✅ 记得 **Repetition 也能「降级」**次要信息，让它可以被忽略？
- ✅ 记得 **Alignment 的「不对齐」反而更吸睛**？
- ✅ 拿到界面截图，能指出被强调的元素并列出所用手法？

一句话总结：**层级 = 用 Size/Color/Contrast/Spacing/Alignment/Repetition 六个手段，把重要的推高、把次要的压低。**
