字体和颜色是视觉基础里最容易被「用力过猛」的两块。新手常见做法是到处换字体、到处加颜色，结果界面又花又乱。真正专业的做法恰恰相反：**用更少的字体、更受限的调色板，换取更强的统一感（cohesion）**。

## 1. 字体排版 Typography

### 1.1 核心原则：less is more

- **字体越一致，用户越不容易困惑**。频繁切换字体会让页面像拼贴，用户分不清哪部分是重点。
- **最多 2 个 font family**。这是硬性经验上限：一个用于标题/展示（display），一个用于正文（body）。超过 2 个基本就是灾难。
- 需要区分层级时，**优先在同一个字体里变化字号/字重**，而不是换字体。

### 1.2 type scale（类型标尺）

不要临时给每个标题想一个字号，而是**预先建立一套等比/递增的字号表**，全局复用：

| 用途 | 字号（示例） | 说明 |
|---|---|---|
| h1 / 大标题 | 48px | 页面主标题 |
| h2 | 32px | 区块标题 |
| h3 | 24px | 小节标题 |
| body | 16px | 正文 |
| caption | 12–14px | 辅助文字 |

预定义 type scale 的好处：一致性、可预测、也方便日后再调整。

> ⚠️ 常见误区：以为「字体越多越有设计感」。恰恰相反，**字体数量是负指标**，2 个以内才是克制。

## 2. 颜色 Color

### 2.1 受限调色板（受限才好用）

一套健康的调色板通常由这几部分组成：

| 组成 | 作用 |
|---|---|
| 主色相 primary hue + 若干变体 variants | 品牌主色及其深浅变化 |
| 次色相 secondary hue | 用于强调、点缀 |
| 灰阶 grayscales | 文字、边框、背景，占大部分面积 |

> ⚠️ 常见误区：以为**颜色越多越丰富**。颜色越多，注意力越分散，越难判断什么是重点。受限调色板才有统一感。

### 2.2 和谐配色的核心判据：看 HUE

判断一组颜色**是否和谐**，关键不是「亮度像不像」，而是**色相 hue 是否相同**：

- **HUE 相同，只变亮度（lightness）/ 饱和度（saturation）→ 和谐**。
- **HUE 不同 → 杂乱，互相争夺注意力**。

### 2.3 RGB vs HSL

| 模型 | 表示 | 适合做什么 |
|---|---|---|
| RGB | `(红, 绿, 蓝)` | 屏幕显示、写 CSS 十六进制 |
| HSL | `(色相 H, 饱和度 S, 亮度 L)` | **人判断「是否同色相」的工具** |

HSL 的第一位就是 **H（Hue）**，一眼就能看出两个颜色是不是同一色相，因此常用来验证配色是否和谐。

### 2.4 和谐 vs 不和谐（常考示例）

```text
✅ 和谐（H 都是 199，只改 S / L）：
   hsl(199, 86%, 51%)   ← 主色
   hsl(199, 100%, 35%)  ← 深一点、饱和一点
   hsl(199, 86%, 90%)   ← 浅色背景
   → 三个颜色色相相同，只是明暗/饱和度不同

❌ 不和谐（H 不同：277 vs 230）：
   hsl(277, 96%, 47%)   ← 紫
   hsl(230, 100%, 89%)  ← 蓝
   → 色相跳变，放在一起显得散乱
```

对应的大纲原始值：和谐组 `(199,86,51) / (199,100,35) / (199,86,90)`；不和谐组 `(277,96,47) / (230,100,89)`。判断时**先看第一个数（H）是否一致**。

> ⚠️ 常见误区：只盯着「亮度是否接近」而忽略**色相**。亮度相近但色相不同，依然是不和谐的。

## 3. 常用工具

| 工具 | 用途 |
|---|---|
| Adobe Color | 生成/探索配色方案 |
| Paletton.com | 快速试色、看色相关系 |
| Colorizer.org | 在 RGB / HSL 等模型间换算、调色 |

这些工具都能帮你直观看到 H / S / L 的变化，验证「是否同色相」。

## 4. 反模式速览（❌ 别这么写）

```css
/* ❌ 字体过多 */
h1 { font-family: "Georgia"; }
h2 { font-family: "Impact"; }
p  { font-family: "Comic Sans MS"; }   /* 已经 3 个了 */

/* ❌ 配色杂乱：每个区块换一个色相 */
.a { color: hsl(277, 96%, 47%); }
.b { color: hsl( 12, 96%, 47%); }
.c { color: hsl(145, 96%, 47%); }      /* 色相各不相同 */

/* ✅ 克制版：同一 hue，只变 S/L */
.a { color: hsl(199, 86%, 35%); }
.b { color: hsl(199, 86%, 51%); }
.c { color: hsl(199, 86%, 85%); }
```

## ✅ 自查清单

- ✅ 页面 font family 是否 **≤ 2 个**？层级是靠字号/字重区分的吗？
- ✅ 是否预先定义了 **type scale**，而不是临时拍字号？
- ✅ 调色板是否**受限**（主色 + 次色 + 灰阶），而不是一堆互不相关的颜色？
- ✅ 判断和谐时，先看 **HSL 的 H（色相）**是否相同？
- ✅ 能认出和谐组 `199,86,51 / 199,100,35 / 199,86,90` 与不和谐组 `277,96,47 / 230,100,89` 的差别？

一句话总结：**字体要少、字号要有规矩；配色要和谐，而和谐的本质是「同色相 hue，只变明暗饱和度」。**
