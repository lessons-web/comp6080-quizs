**示能（Affordance）** 指的是：一个元素的**视觉属性**让用户知道「我可以拿它做某事」。它是交互发生**之前**的提示，直接决定 UI 的第三层目标——**让用户会做事**。示能没做好，用户就会对着界面发呆：「这个能点吗？点了会怎样？」

## 1. 定义与直观例子

- 门口的**门把手**：它的形状和位置本身就在说「请握住我拉/推」——你不需要读说明书。
- 网页里的**按钮**：凸起的方块、圆角、描边、投影，都在暗示「我是可以点的」。

```text
示能 = 元素外观 → 用户推断出「可执行的操作」
```

同一个人**不需要被教**就知道门把手可以拉，这就是示能成功的标志。

## 2. 三种类型（★ 核心考点）

### 2.1 Explicit Affordance（显式示能）

**明确、直接地告诉用户怎么操作**，把动作写出来或画出来。

- 例：按钮上直接写 **"Click here"** / 「立即购买」。
- 例：箭头图标 `→` 明确表示「往这走」。
- 特点：几乎不会误解，但措辞啰嗦时显得笨拙。

### 2.2 Pattern Affordance（模式示能）

**用约定俗成的模式（convention）暗示**，靠用户过往经验来理解。

| 视觉模式 | 用户联想到 |
|---|---|
| 蓝色 + 下划线文字 | 这是一个**链接** |
| 三条横线（汉堡图标 ≡） | 点开是**菜单** |
| 面包屑 `首页 > 分类 > 详情` | 当前所处**层级**，可回跳 |
| 放大镜 | **搜索** |
| 购物车 | **购买 / 结算** |
| 齿轮 | **设置** |

- 特点：效率高、界面干净，但**依赖用户已经学会这个约定**。
- 模式示能是「惯例」的产物，所以 UI 检查清单里强调**遵循通用标准与惯例**。

### 2.3 False Affordance（虚假示能）

**看起来能操作、实际却不能**——这是要**极力避免**的，因为它制造最大的困惑。

```text
❌ 看起来像按钮的纯装饰方块（点了没反应）
❌ 蓝色带下划线的文字，其实是普通文本（不是链接）
❌ 可点的区域做不到（如卡片看起来可点，实际只有小角落能点）
❌ 灰色按钮不区分「禁用」和「看起来灰但能点」
```

> ⚠️ 常见误区：**分不清「示能」和「反馈（feedback）」**。示能是交互**前**的提示（「我猜它能点」），反馈是交互**后**的响应（「我点了，它变了/弹了提示」）。本来该给示能的地方给了反馈、或反过来，都是错。

## 3. 三者对比表

| 类型 | 靠什么起作用 | 例子 | 风险 |
|---|---|---|---|
| Explicit 显式 | 明确文字/说明 | "Click here"、箭头 | 啰嗦、不优雅 |
| Pattern 模式 | 约定俗成的样式 | 蓝下划线=链接、≡=菜单 | 依赖用户已学会 |
| False 虚假 | 视觉假装可交互 | 装饰方块像按钮 | **必须避免**，最易困惑 |

## 4. 示能 vs 反馈（最易混淆）

| 维度 | 示能 Affordance | 反馈 Feedback |
|---|---|---|
| 发生时机 | 交互**之前** | 交互**之后** |
| 作用 | 提示「可以做什么」 | 告知「刚刚发生了什么」 |
| 例子 | 按钮看起来能点 | 点击后按钮变色 / 弹出成功提示 |
| 缺失后果 | 用户不敢点、不会用 | 用户不确定操作是否生效 |

```text
用户看到按钮（示能） → 点击 → 系统响应（反馈）
   ── 前 ──                    ── 后 ──
```

## 5. 设计应用与反模式

```text
✅ 链接：蓝色 + 下划线 + hover 变色（Pattern + 反馈）
✅ 主按钮：实心主色 + 圆角 + hover 加深（Pattern 示能 + 反馈）
✅ 图标贴合现实：放大镜=搜索、软盘=保存（Pattern 示能）

❌ 装饰性元素长得像按钮（False affordance）
❌ 只有 hover 才显示的可点区域，静止时看不出可点
❌ 把禁用态和可点态做得一模一样，用户分不清
```

## 6. 判断练习

- 一段**蓝色带下划线的文字** → Pattern affordance（链接）。
- 按钮上写着 **"Click here to continue"** → Explicit affordance。
- 一个**看起来像按钮但点了没反应**的方块 → False affordance（❌）。
- **点击后按钮短暂变暗** → 这是 **反馈**，不是示能。

## ✅ 自查清单

- ✅ 能用一句话定义示能：视觉属性暗示「可以拿它做某事」？
- ✅ 能区分 **Explicit / Pattern / False** 三类并各举例子？
- ✅ 知道 **False affordance 必须避免**，是最易造成困惑的一类？
- ✅ 牢记 **示能=交互前提示、反馈=交互后响应**，二者不同？

一句话总结：**示能是「交互前的钩子」，三种类型里显式最直白、模式最常用、虚假最危险。**
