这一篇是**名词附录**性质的内容：课程里只点名提到四个进阶概念，没有展开成方法论。它们的定位是「**了解即可**」——考试可能考「这是干什么的」，但不需要你会动手实现。下面给每个概念 2–3 句解释，并配一个实际场景帮助记忆，最后再补一点「它和基础原则的关系」，方便你建立整体印象。

## 1. Dark Mode（深色模式）

深色模式把界面的底色从亮色换成深色、文字换成浅色，是一套**独立于浅色主题的第二套配色**，而不是简单把颜色反过来。它需要考虑对比度、避免纯黑纯白刺眼、并保持品牌色在深底上的可读性。

- **不是反转颜色**：直接 `invert` 会让图片、品牌色变得怪异，正确的做法是单独设计一套深色变量。
- **典型增益**：夜间/暗光环境下更护眼、更省电（OLED 屏幕纯黑像素不发光）。
- **要注意**：深色下阴影几乎不可见，层级往往要靠**更亮的背景块**而不是阴影来区分。

> 实际场景：阅读类 App、开发者 IDE 常提供 Dark Mode 切换；用户晚上躺在床上刷手机时更舒适。

## 2. Microinteractions（微交互）

微交互是界面中**围绕单一任务的小型、短促的交互反馈**，通常由「触发器 → 规则 → 反馈 → 循环与模式」构成，作用是在操作瞬间告诉用户「发生了什么」。它往往很小（一个动画、一次震动、一次变色），却能显著**提升可用性与愉悦感**。

- **触发器**：用户发起（点击/滑动/到达某状态）或系统发起（收到通知）。
- **反馈**：最直观的那一步，例如变色、弹跳、声音、震动。
- **价值**：把「我操作成功了吗」的疑问在 0.3 秒内消解掉，本质是给交互配上了**反馈**（呼应示能章节「交互后的响应」）。

> 实际场景：点赞按钮点下去时**心形弹跳一下**；下拉刷新时出现转圈动画；开关拨动时的滑动动效。

## 3. Designing for Emotions（情感化设计）

情感化设计关注用户在使用产品时的**情绪体验**——不只是「能用」，还要**让人喜欢、信任、感到亲切**。手段包括插画、文案语气、空状态设计、动效节奏等，让产品有「性格」。它与 UX 的可信度、品牌认同密切相关。

- **空状态**：列表为空时不是一片空白，而是给一句鼓励 + 一个行动按钮。
- **文案语气**：报错时用平实友好的措辞，而不是暴露技术堆栈。
- **边界**：情绪设计不能喧宾夺主，任务流程里过度卖萌会拖慢效率。

> 实际场景：404 页面配一张幽默插画和轻松文案（而不是冷冰冰报错）；支付成功时放一个庆祝小动画。

## 4. Cognitive Load（认知负荷）

认知负荷指用户**处理信息时大脑承担的负担**。界面越乱、选择越多、需要记忆的东西越多，负荷越高，用户越容易出错和放弃。降低负荷的常见手段有：**识别优于回忆、减少选项、分步引导、遵循惯例**。

- **识别优于回忆**：把选项摆在眼前（识别），比让用户凭记忆输入（回忆）轻松得多。
- **减少选择**：选项过多会带来「选择瘫痪」，要敢于删掉不必要的选项。
- **分步引导**：把一个复杂表单拆成几步，每一步只处理一件事，负荷显著下降。

> 实际场景：结账页面把「填写地址」拆成一步一步，而不是一次甩出 15 个输入框；「记住我」省去重复输入。

## 6. 它们和基础原则的关系

这四个概念虽然进阶，但都能挂回前面学过的基础原则：

| 进阶概念 | 挂钩的基础原则 |
|---|---|
| Dark Mode | 配色（对比度）+ 一致性（两套主题都要自洽） |
| Microinteractions | **反馈**（交互后的响应） |
| Designing for Emotions | 品牌、可用性、用户体验 |
| Cognitive Load | 视觉层级、极简、遵循惯例 |

也就是说，先把**对齐、层级、示能、反馈、一致性**这些基础打牢，这四个概念才会真正为体验加分。
