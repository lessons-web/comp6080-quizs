人眼对**对齐**和**一致的模式**有天生的偏好：一旦元素沿同一条线排列，大脑就不需要额外费力去解析，界面立刻显得「不吓人」。对齐是 UI 里成本最低、收益最高的整洁手段，而达成对齐最常用的工具就是**网格（grid）**。

## 1. 为什么要对齐

- 人对**规律、对齐**的图形有天然好感，对**参差不齐**的排布会本能地觉得「乱」。
- 对齐让视线有轨道可循，降低认知负担，因此它服务于 UI 的第一层目标——**让用户不害怕**。
- 对齐的副产品是**一致性**：同一套对齐规则贯穿全页面，用户会形成预期。

> ⚠️ 常见误区：以为对齐只是「好看」。对齐的本质是**降低认知成本**，让用户把注意力留给内容而不是「这排版怎么歪了」。

## 2. 网格（Grid）是手段，不是目的

网格是**实现对齐的工具**。它先规定好一套看不见的竖线（列），再让所有卡片、图片、文字都吸附到这些竖线上，从而获得天然的对齐。

```text
| col1 |  | col2 |  | col3 |  ...  | col12 |   ← 内容吸附到列边缘
  ↑gutter↑ 列间距
 margin                              margin   ← 内容不进入 margin
```

关键词：

| 术语 | 含义 |
|---|---|
| grid | 决定列数/间距的整体骨架 |
| column | 网格中的一列，内容对齐到它的**边缘** |
| gutter | 相邻列之间的间距（列间距） |
| margin | 网格左右两侧的外边距，内容**不进入** |
| visual alignment | 用网格获得的视觉对齐效果 |

## 3. BBC 案例的具体参数（常考数字）

BBC 的页面设计是这门课的经典案例，参数要记住：

| 参数 | 数值 | 原因 |
|---|---|---|
| 内容区最大宽度 | **1200px** | 太宽每行字数过多，**可读性**下降 |
| 列数 | **12 列** | 见下一节，可灵活切分 |
| 列间距 gutter | **16px** | 常考的固定值 |
| 内容区两侧 | margin | 内容对齐到**列的边缘**，但不进入 margin |

```text
← 1200px 上限（居中） →
┌──────────── 内容区 ────────────┐
│ ┌─┐16┌─┐16┌─┐ ... 共 12 列 ... │
│ └─┘  └─┘  └─┘                  │
└────────────────────────────────┘
      margin                   margin
```

> ⚠️ 常见误区：把 **column 边缘** 和 **margin** 搞混。内容应该贴着**列的边缘**对齐，而不是贴着 margin 或任意位置；margin 是列网格之外留的空白，是「不能放内容」的区域。

## 4. 为什么是 12 列

12 的强壮之处在于它有**很多因数**——可被 **1 / 2 / 3 / 4 / 6** 整除，于是同一张网格能表达大多数常见布局：

| 想做的布局 | 每块占几列 | 是否整除 |
|---|---|---|
| 整体 1 栏 | 12 | ✅ |
| 2 等分 | 6 + 6 | ✅ |
| 3 等分 | 4 + 4 + 4 | ✅ |
| 4 等分 | 3 × 4 | ✅ |
| 6 等分 | 2 × 6 | ✅ |
| 侧栏 + 主区 | 4 + 8 | ✅ |

如果换成 10 列，就做不出漂亮的 3 等分或 4 等分；换成 16 列又太碎。**12 是兼顾灵活性与简洁的折中**。

> ⚠️ 常见误区：以为**列数越多越好**。列数越多，网格越细碎，反而更难对齐、更难维护；选择列数要服务于实际布局需求。

## 5. 常见反模式（❌ 别这么写）

```css
/* ❌ 反模式 1：魔法数字对齐，靠手动微调 */
.card { margin-left: 37px; }
.card + .card { margin-left: 41px; }  /* 每次都不一样 */

/* ❌ 反模式 2：内容贴到 margin 上，破坏网格 */
.content { padding-left: 0; }         /* 直接顶到最左 */

/* ❌ 反模式 3：列宽 + gutter 用奇怪的比例 */
.col { width: 16.67%; }               /* 6 等分却算上了 gutter，导致溢出 */
```

✅ 正确做法：用网格系统（如 12 列 + 16px gutter）统一约束，所有元素吸附到列边缘。

## 6. 小练习：判断用了什么原则

- 页面三张卡片等宽并排 → 用了 **3 等分网格**（各占 4 列）。
- 左侧导航固定 4 列、右侧内容 8 列 → 用了 **12 列中的 4+8 组合**。
- 整页内容居中且不超过 1200px → 用了 **1200px 内容区上限**保证可读性。
- 卡片之间间距处处相等 → 用了 **16px gutter**。

## ✅ 自查清单

- ✅ 知道对齐服务于「让人不害怕」，网格只是**手段**？
- ✅ 记得 BBC 案例三参数：**1200px 上限 / 12 列 / 16px gutter**？
- ✅ 能说出 12 列可被 **1、2、3、4、6** 整除，所以灵活？
- ✅ 清楚内容对齐到**列边缘**而非 margin，且不进入 margin？

一句话总结：**网格是对齐的骨架，12 列 + 16px gutter + 1200px 上限是这套骨架的黄金参数。**
