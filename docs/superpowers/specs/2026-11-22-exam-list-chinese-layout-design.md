# 试卷列表中文与列宽设计

## 目标

试卷列表默认展示中文标题和描述，并缓解名称列过宽、右侧信息列拥挤的问题。

## 设计

- 显示字段优先级为 `titleZh`、`descriptionZh`，缺少中文字段时回退到 `title`、`description`。
- 表格固定布局，列宽依次为：试卷名称 40%、标签 25%、发布时间 15%、总分 9%、操作 11%。
- 表格设置合理的最小宽度，较窄视口允许横向滚动，不挤压日期、总分和操作按钮。
- 操作按钮保持单行；名称列的描述继续单行省略。
- 沿用现有纸张色调、标签样式、筛选与时间倒序行为。

## 验收标准

- 具有中文字段的试卷在列表中显示中文标题和描述；缺失中文字段时仍有英文回退。
- 表格列宽明确且名称列不再占据大部分宽度。
- 操作按钮不发生逐字换行，窄屏可横向滚动。
- 现有筛选、排序和访客锁定行为不变，相关测试通过。

## 验证

- 为中文回退、列布局及操作按钮单行行为补充或调整组件测试。
- 运行组件测试、内容测试和 TypeScript 检查。
