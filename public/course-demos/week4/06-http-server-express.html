6.1

这一节先抓住两件事focus on two ideas

A

HTTP 是一次请求-响应对话

浏览器发出 method、path、headers、body；服务器处理后回 status、headers、body。

B

Express 用 method + path 匹配路由

GET / POST / PUT / DELETE 不只是单词，它们和资源路径一起决定了请求落到哪段处理逻辑。

一句话
XHR、fetch、Promise、async / await 讲的是“客户端怎么发”；HTTP Server 与 Express 讲的是“服务端怎么接并怎么回”。
