怎么运行这些演示serve locally

第 01 节双击打开就能用；但 02–05 节涉及网络请求和本地兜底文件， 浏览器在 file:// 协议下会拦截这类读取，所以请用本地服务器打开整个 week4 目录。

bash 在 COMP6080/2026T3/week4 目录下执行 
# 任选一种，然后在浏览器打开 http://localhost:8080
python3 -m http.server 8080

# 或者
npx serve .
提示
课堂断网的预案：02–05 节的演示台都带「本地兜底」开关。 远程接口失败时，代码会转去读 assets/fallback-users.json， 返回结构与远程接口同构，页面渲染逻辑完全不用改 —— 这本身就是一次真实的错误处理示范。
注意
这些页面的代码不依赖任何库。 没有 jQuery、没有 axios、没有构建工具。每一页的 <script> 就是课上的全部代码，学生可以直接「查看网页源代码」对照。

# 回答的问题 核心 API 最容易被考的点
01 数据在传过去之前，长什么样？ JSON.stringify / parse JSON 是字符串，不是对象；key 必须双引号、无尾逗号
02 不刷新页面，怎么把服务器数据插进 DOM？ XMLHttpRequest 只有网络层失败才走 onerror；4xx/5xx 要走 status
03 有没有更好用的请求方式？ fetch() fetch 遇到 404 不会 reject，必须自己判 res.ok
04 「未来才会有的值」怎么被组织和编排？ Promise 状态不可逆；all / race / allSettled 的差别
05 能不能写得像同步代码一样？ async / await async 总是返回 Promise；await 失败即抛出，所以能 try/catch
口诀
一句话串起来：先把数据变成字符串（01）→ 用 XHR 送出去（02）→ 换成 fetch 更好用（03） → 背后是 Promise（04）→ 最后用 async/await 写得像同步（05）。
